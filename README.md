# Бюро находок

Курсовой проект по разработке информационной системы автоматизации работы бюро находок.

## Технологии

- C#
- .NET 8.0 LTS
- Windows Forms
- SQL Server 2022 Express
- Microsoft.Data.SqlClient 6.1.2
- Visual Studio 2022

## Возможности системы

- авторизация пользователя;
- просмотр зарегистрированных найденных вещей;
- добавление найденной вещи;
- регистрация заявления о пропаже;
- просмотр и удаление заявлений о пропаже;
- поиск найденных вещей по нескольким параметрам;
- выдача найденной вещи владельцу;
- регистрация факта выдачи;
- создание уведомления владельцу.

## Запуск проекта

1. Установить Visual Studio 2022 с поддержкой разработки классических приложений .NET.
2. Установить SQL Server 2022 Express и SQL Server Management Studio.
3. Открыть файл `BuroNahodok.sln`.
4. Выполнить восстановление NuGet-пакетов.
5. В SQL Server Management Studio выполнить скрипт `Database/BuroNahodok_Create.sql`.
6. Запустить проект из Visual Studio.

## Подключение к базе данных

По умолчанию приложение подключается к экземпляру SQL Server:

`Server=.\SQLEXPRESS`

Если на компьютере используется другое имя экземпляра SQL Server, необходимо изменить строку подключения в файле `Database.cs`.

## Структура проекта

- `BuroNahodok.sln` — решение Visual Studio;
- `BuroNahodok.csproj` — проект приложения;
- `LoginForm.cs` — форма авторизации;
- `MainForm.cs` — главное меню;
- `FoundForm.cs` — работа с найденными вещами;
- `LostForm.cs` — работа с заявлениями о пропаже;
- `AddForm.cs` — регистрация найденной вещи;
- `AddLostForm.cs` — регистрация заявления о пропаже;
- `SearchForm.cs` — поиск найденных вещей;
- `Database.cs` — подключение и работа с базой данных;
- `Database/BuroNahodok_Create.sql` — скрипт создания базы данных и начальных данных.

## Примечание

Папки `bin`, `obj` и `.vs` в репозиторий не включаются, так как они содержат локальные и автоматически создаваемые файлы Visual Studio.
